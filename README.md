## О проекте

**Фракталы** - математические объекты, обладающие дробной размерностью в отличие от привычных геометрических фигур целой размерности. Их главное свойство - **самоподобие**: при рассмотрении объекта в разном масштабе обнаруживаются одни и те же элементы.
Линейные фракталы называются так потому, что строятся с помощью линейных преобразований плоскости. Такие преобразования сжимают, отражают, поворачивают и перемещают изображение, но прямые линии при этом остаются прямыми.

4. Исследовать влияние коэффициентов на форму фрактала.

## Как это работает

Аффинное или линейное преобразование координат задается двумя линейными уравнениями:

```
x' = a·x + b·y + e
y' = c·x + d·y + f
```

Алгоритм построения:

1. Задается набор аффинных преобразований, каждому сопоставлена вероятность `p` его применения (сумма вероятностей равна `1`).
2. Берется начальная точка с координатами `x = 0`, `y = 0`.
3. Случайным образом выбирается одно из преобразований и применяется к текущей точке.
4. Полученная точка отображается на плоскости цветом, связанным с примененным преобразованием.
5. Шаги 3-4 повторяются, пока изображение не станет достаточно детальным.

## Поддерживаемые фракталы

Каждый фрактал задается отдельным набором коэффициентов, поэтому добавление нового не требует изменения кода программы.

| Фрактал | Преобразований | Статус |
| --- | --- | --- |
| Лист папоротника (Барнсли) | 4 | планируется |
| Треугольник Серпинского | 3 | планируется |
| Дракон Хартера - Хейтуэя | 2 | планируется |
| Кристалл | 4 | планируется |
